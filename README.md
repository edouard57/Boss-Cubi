# 🧊 Cubi-mc-plugins


## 🧟 Zombinel Boss

Un boss zombie personnalisé pour pimenter la survie et créer des événements.

**Commande :**
```
/summonboss
```

**Description :**
- Ouvre le menu d'apparition des Boss.
- Comme Zominel et Golgy (par exemple).
- Parfait pour des events, défis ou combats de groupe

---

## ⚙️ Installation

1. Télécharger le plugin souhaité
2. Placer le fichier `.jar` dans le dossier `plugins/`
3. Redémarrer le serveur
4. Profiter 🚀

---

## 🛠️ Compatibilité

- Serveur : **Paper / Spigot**
- Version Minecraft : 1.21.10
